Konfigurasi Google Sheets (GAS)

Masukkan Web App URL dari Google Apps Script yang telah Anda publikasikan agar data dapat tersimpan secara online ke Google Sheets.

Langkah Pengaplikasian Google Apps Script:

  1. Buka Google Sheets baru.
  2. Klik menu Extensions (Ekstensi) > Apps Script.
  3. Hapus semua kode bawaan, lalu **paste kode GAS** (`Code.gs`) yang tersedia.
  4. Klik tombol Deploy > New Deployment.
  5. Pilih Select type ⚙️ > Web app.
  6. Set **Execute as**: Me dan **Who has access**: Anyone (Siapa Saja).
  7. Klik **Deploy**, izinkan akses akun, lalu **Copy Web App URL**.
  8. Paste URL tersebut pada kolom input di atas lalu klik **Simpan URL**.
